# Umbriel Keyboard Shortcuts

**Note:** `Mod` refers to the **Super** (Windows) key.

## Applications & Launcher
| Shortcut | Action |
| :--- | :--- |
| `Mod + T` | Open Terminal (Kitty) |
| `Mod + E` | Open File Manager (Thunar) |
| `Mod + Space` | Open App Launcher (Fuzzel) |

## Noctalia Shell
| Shortcut | Action |
| :--- | :--- |
| `Mod + Comma` | Open Noctalia Settings |
| `Mod + N` | Toggle Notification Center |
| `Mod + Y` | Toggle Wallpaper Picker |
| `Mod + V` | Toggle Clipboard History |
| `Mod + Shift + N` | Toggle Notepad |
| `Super + X` | Toggle Power Menu |
| `Mod + Alt + L` | Lock Screen |

## Window Management
| Shortcut | Action |
| :--- | :--- |
| `Mod + Q` | Close Window |
| `Mod + Left / H` | Focus Window Left |
| `Mod + Right / L` | Focus Window Right |
| `Mod + Up / K` | Focus Window Up |
| `Mod + Down / J` | Focus Window Down |
| `Mod + Shift + Left / H` | Move Column Left |
| `Mod + Shift + Right / L` | Move Column Right |
| `Mod + Shift + Up / K` | Move Window Up |
| `Mod + Shift + Down / J` | Move Window Down |

## Layout & Columns
| Shortcut | Action |
| :--- | :--- |
| `Mod + Shift + V` | Toggle Floating Mode |
| `Mod + BracketLeft` | Consume Window Left |
| `Mod + BracketRight` | Consume Window Right |
| `Mod + B` | Expel Window Right (Split Toggle) |
| `Mod + Period` | Expel Window Right |
| `Mod + R` | Cycle Column Width |
| `Mod + Shift + R` | Cycle Column Width Backwards |
| `Mod + Ctrl + R` | Reset Column Width to 50% |
| `Mod + F` | Maximize Column (Keep Borders) |
| `Mod + Shift + F` | Fullscreen Window |
| `Mod + W` | Toggle Tabbed Display |

## Workspaces & Overview
| Shortcut | Action |
| :--- | :--- |
| `Mod + 1..9` | Switch to Workspace 1-9 |
| `Mod + Shift + 1..9` | Move Window to Workspace 1-9 |
| `Mod + U` | Next Workspace |
| `Mod + I` | Previous Workspace |
| `Mod + Shift + U / I` | Move Workspace Down / Up |
| `Mod + MouseScroll` | Scroll through Workspaces |
| `Mod + Tab` | Toggle Overview |
| `Mod + D` | Toggle Overview |

## Monitor Management
| Shortcut | Action |
| :--- | :--- |
| `Mod + Ctrl + Left / H` | Focus Monitor Left |
| `Mod + Ctrl + Right / L` | Focus Monitor Right |
| `Mod + Shift + Ctrl + Left / H` | Move Window to Monitor Left |
| `Mod + Shift + Ctrl + Right / L` | Move Window to Monitor Right |

## Media & System
| Shortcut | Action |
| :--- | :--- |
| `Print` | Screenshot (Area to Clipboard) |
| `Shift + Print` | Screenshot (Full Screen to Clipboard) |
| `XF86AudioRaiseVolume` | Volume Up |
| `XF86AudioLowerVolume` | Volume Down |
| `XF86AudioMute` | Mute Audio |
| `XF86AudioPlay / Pause` | Toggle Media Playback |
| `XF86AudioNext / Prev` | Next / Previous Track |
| `XF86MonBrightnessUp / Down` | Brightness Up / Down |
